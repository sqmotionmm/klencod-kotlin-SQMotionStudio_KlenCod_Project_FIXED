# SQ Motion Studio

تطبيق Android أصلي بلغة Kotlin، معدّل من قالب KlenCod IDE إلى محرر Motion Graphics أولي.

## الوظائف الحالية
- معاينة تصميم عمودية 1080×1920.
- إضافة/تعديل طبقة نص وتغيير لون النص.
- استيراد صورة من الجهاز ووضعها في المعاينة.
- تشغيل معاينة متحركة مع شريط زمني وتحديد مدة المشروع.
- تغيير نمط الحركة وإعادة ضبط المشروع.
- تصدير الإطار الحالي إلى PNG في Pictures/SQMotion.

## حدود هذه النسخة
هذه نسخة أولية قابلة للتوسعة وليست محرر فيديو كاملًا بعد: تصدير MP4، مسارات صوتية، طبقات متعددة مستقلة ومفاتيح Keyframe قابلة للتحرير لم تُنفذ في هذه النسخة. زر التصدير يحفظ إطار PNG فقط.

## البناء داخل KlenCod IDE
1. فك ضغط ZIP.
2. افتح المجلد الذي يحتوي على `settings.gradle` في KlenCod IDE.
3. انتظر مزامنة Gradle مع الإنترنت إن طلب ذلك.
4. اختر Build APK.

الحزمة: `com.sq.create` — لا تغيّر سطر package في MainActivity.kt.
